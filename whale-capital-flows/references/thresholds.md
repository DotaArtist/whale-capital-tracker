# 大额门槛 · 什么算「大钱 + 重大新闻」

两条准入资格，满足其一即可入账：
1. **金额门槛**：达到下表默认值；
2. **前 20 资格**：未达金额门槛，但进入当期（自然季度）该类型全球前 20。

用户可显式覆盖门槛（如"只看 50 亿以上"），覆盖值写进产出摘要。

## 默认金额门槛（亿美元）

| event_type | 门槛 | 说明 |
| --- | --- | --- |
| `ipo` | ≥ 5 | 约 35 亿人民币，跨市场可比的"大型 IPO" |
| `follow_on` | ≥ 5 | 增发/配股常比 IPO 大，同门槛 |
| `convertible` | ≥ 5 | |
| `bond` | ≥ 10 | 债券单笔天然更大 |
| `spac` | ≥ 3 | SPAC 信托规模普遍偏小 |
| `despac` | ≥ 20 | 含 PIPE 合计 |
| `gdr` | ≥ 5 | |
| `reits` | ≥ 3 | |
| `buyback` | ≥ 20 | 回购计划金额通常远大于单次募资 |
| `ma` | ≥ 50 | 只记巨型交易，中型并购量大且常未成行 |

## 「重大新闻」的判断辅助（金额之外的加分信号）

- 官方公告含 "largest since ..." / "史上最大" / "record" 表述；
- 主体是该国/该行业龙头（市值前 10%）；
- 首创结构（首单 GDR、首批 REITs 类别）；
满足金额门槛但无任何新闻性的边缘事件（如常规滚续债券），仍入账但 note 标注「例行滚续」。（入账即大额，不存 is_major 字段，校验器按门槛强制）

## 反例（明确不入账）

- 门槛之下的常规操作（小额回购执行、季度分红——分红整体不采集，只有特别分红按 `returning` 且 ≥ 20 亿$ 才记）；
- 传闻、意向、无官方公告的"知情人士称"；
- 私有市场交易（PE 基金募集、私有公司融资）；
- 已在 seed.ipos.jsonl 记录且金额未过门槛的 IPO。
